# Plan02 execution decisions

Ordered rulings recorded during implementation and final review. Each states the cost if wrong.

Ruling: normalize D1-D3 headings to Task 1-3, retaining labels ? bundled task-start parser requires Task headings ? cost if wrong: no product behavior change.
Ruling: preserve original XLSX envelope serialization and extend fixed generated names/MIME by suffix ? avoids invalidating saved deterministic jobs while supporting document bundles ? cost if wrong: every transport/storage boundary must enforce the same MIME/name relationship.
Ruling: D1 refuses unsupported drawings/images/footnotes/revisions/fields before edits rather than implementing lossy DOCX editing ? approved design allows refusal and image handling is deferred ? cost if wrong: complex existing DOCX needs simplification until support expands.
Ruling: new PDFs retain a companion DOCX bound to the exact parent version, companion bytes count toward owner quota and publish atomically ? lineage must not follow a latest-file pointer ? cost if wrong: more private storage and stricter quota use.
Ruling: preview pages are bounded, produced in sandbox batches under the existing per-call transport/profile ceilings and staged before publication ? unlimited page output would violate current isolation/size contract ? cost if wrong: very large documents can be refused at explicit page/size limits rather than published with incomplete previews.
Ruling: normalize only native Windows scratch paths with the extended path prefix, keeping portable generated names unchanged - MAX_PATH was the shared root cause of all 11 baseline failures - cost if wrong: cleanup and staging must recognize the same native prefix.
Ruling: partial PDF rebuilding uses a separate host-approved artifact_rebuild_pdf_text_only tool with pinned parent, full replacement text and exact omitted-page list - a model-controlled consent boolean would bypass informed approval - cost if wrong: one additional tool and an explicit approval step for mixed documents.
Ruling: bound Word/PDF rendering and PDF extraction to 20 pages, 20 MiB files and existing 90s/1 GiB renderer limits; extraction expanded streams capped at 8 MiB/page and 32 MiB total - measured bounded execution is required and image/OCR work is deferred - cost if wrong: oversized documents are explicitly refused until limits are revisited.
Ruling: PDF inspect exposes page offset, bounded text chunks and next_text_offset while preserving the legacy wire shape for a zero text offset - a truncated preview cannot be treated as complete source text for a rebuild - cost if wrong: additional read calls for long pages.
Ruling: raise chat schema allowance to 10000 only with Workspace Artifacts enabled, retaining 6000 otherwise, after removing redundant create schema branches - the measured complete artifact catalog needs 6167 tokens and must fit with ordinary host tools - cost if wrong: larger tool schema context when this feature is enabled; overall run/spend limits are unchanged.
Ruling: preserve pinned JEV v2.1.3/v2.1.4 routes only when the capability catalog is unchanged, while advertising document types under v2.1.5 - avoids invalidating unrelated resumable chats after adding Word/PDF routing metadata - cost if wrong: old pinned decisions continue using their original route rather than reclassifying mid-run.
Ruling: retain existing raw RAG-copy behavior and immutable old metadata; page previews are generated atomically for uploaded/created/edited Word/PDF versions - preserves exact-source copies and avoids rewriting historical versions - cost if wrong: a raw or historical RAG copy has download-only preview until a supported edit creates a new version.
Final: Ruling: OCR and image-content editing remain deferred; accurate omission detection is required and nested Form images are fixed in this pass - text-first scope was approved - cost if wrong: users need another tool for OCR/image changes.
Final: Ruling: full Office fidelity remains outside scope, with conservative refusal of unsupported drawings, footnotes, revisions, fields and special run content - refusing is preferable to silently losing content - cost if wrong: more existing Word files need simplification.
Final: Ruling: PDF reconstruction may reflow original pagination and graphical layout - user explicitly accepted content/format changes without page fidelity - cost if wrong: edited PDFs may differ visually from originals.
Final: Ruling: keep documented page, size and resource bounds - bounded refusal protects the existing sandbox contract - cost if wrong: large legitimate documents cannot be processed yet.
Final: Ruling: keep disclosed oversized DOCX outline-node truncation rather than expand the inspection API in this plan - source content remains intact and the tool reports truncation - cost if wrong: the agent may be unable to inspect every cell or long paragraph before a targeted edit.
Final: Ruling: no automatic preview backfill for historical/raw RAG copies - immutable bytes and metadata remain unchanged - cost if wrong: these copies stay download-first until a supported new edit.
Final: Ruling: do not claim live-model tool-selection acceptance from fixture tests - no paid provider run was performed - cost if wrong: real models may need later prompt/tool-routing tuning.
Final: Ruling: leave Google Connectors and Automations to Plans03/04 - approved sequencing requires document acceptance first - cost if wrong: remote file writes and schedules are unavailable in this branch.
Final: Ruling: production deployment and migration execution remain a separate operational step - this task authorizes branch implementation and isolated QA, not changing the running user environment - cost if wrong: new features remain inactive until deployed.
